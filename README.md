# Library Management System

## Project Description
The Library Management System is a Python-based project developed to manage library activities easily and efficiently. It helps librarians maintain book records, student details, issue and return records, reservations, and library reports.

The system uses a menu-driven interface and JSON files to store data.

## Objectives
- To manage library book records.
- To register and maintain student details.
- To issue and return books.
- To calculate overdue fines.
- To manage book reservations.
- To maintain issue and return history.
- To generate library reports and statistics.
- To save and restore library data.

## Technologies Used
- **Programming Language:** Python
- **Platform:** Google Colab
- **Data Storage:** JSON
- **File Handling:** CSV and JSON
- **Version Control:** GitHub

## Features
1. Add new books.
2. Remove books.
3. Display all books.
4. Search books by ID, title, or category.
5. Register students.
6. Display student records.
7. Issue books to students.
8. Return issued books.
9. Calculate overdue fines automatically.
10. Reserve books.
11. Notify students when reserved books become available.
12. Maintain issue and return history.
13. Display library dashboard and statistics.
14. Identify most borrowed books.
15. Export book records to CSV.
16. Create JSON backups and restore records.

## How to Run the Project
1. Open Google Colab.
2. Create a new Python notebook.
3. Copy the project code into a code cell.
4. Run the cell.
5. Select the required operation from the main menu.
6. Enter the requested details.
7. The system automatically saves records in a JSON file.
